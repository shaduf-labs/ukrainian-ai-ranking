Рейтинги за задачами · оновлено 21 вересня 2026

Є рейтинг тексту. Немає чесного спільного балу для всього.

Ми не додаємо ELO за українську генерацію до підтримки API, Excel чи субтитрів. Нижче — де є виміряні рядки, де є корисний шортлист, а де немає оцінки.

НапрямСтатусНайкорисніша діяДжерело поруч
Текст і документиЄ різні модельні тести, експертний граматичний тест, окремі сигнали оцінки перекладу й один вузький результат для фахового перекладу з перевіреними прикладами.Для генерації подивіться ELO UkrQualBench; для норми мови — окрему таблицю UNLP; для повторюваних термінів підготуйте погоджену двомовну опору та перевірте документований глосарійний маршрут.UkrQualBench · UNLP grammar · UNLP translation review · DeepL glossary
Голос і субтитриЄ названі API-функції, локальний гуцульський WER і одна пряма пара відкритих чекпойнтів на FLEURS Ukrainian; оцінок сервісів немає.Для локального читаного аудіо можна почати з Orukeet проти Parakeet; для API — виберіть інтеграцію й перевірте короткий запис.Orukeet r3 · Google · Azure
ТаблиціДля тексту в клітинках Sheets AI function бачить заданий діапазон; ChatGPT має окремі надбудови для Excel/Sheets, Copilot у Excel — режими плану, чату й редагування. Українського рейтингу цілісності немає.Оберіть середовище, а потім перевірте цільову книгу: формули, дати, гривні й експорт. WTM-Bench пояснює, чому відповідь у чаті не є таким тестом.Google · OpenAI · Microsoft · WTM-Bench
Робочі сценаріїНемає спільного доказу для клієнтських результатів.Перевірте найризиковіший крок: для довгого документа додайте пізню правку й звірте, чи лишилися бриф і факти.Практичні маршрути

Як читати сторінки: «виміряно» означає конкретний тест, метрику, версію й дату. «Задокументовано» означає, що постачальник описує функцію. Друге не є місцем у рейтингу.
